# 童年头像 Prompt 模板 v1（2026-08-13，与 Yi 共同定稿）

两步管线：视觉模型读照片 → 填变量 → 拼装成生成 prompt → Seedream 出图。

## 第一步：特征提取（给视觉模型的指令）

> 仔细观察这张童年照片中的人物，输出以下 JSON。注意：`distinctive` 里只放这个孩子**最有辨识度、偏离普通小孩平均长相**的 2-3 个特征（比如特别大的耳朵、特别圆的脸、很有特点的刘海）——普通的特征不要放进去。

```json
{
  "basic": {
    "gender": "女孩 | 男孩",
    "ethnicity": "东亚 | 欧美 | 中东 | 非裔 | 拉美 | 南亚 | 混血…",
    "age": "约X-X岁"
  },
  "hair": {
    "color": "乌黑 | 棕色 | 金色…",
    "length": "具体到参照物：发尾在耳朵上方/齐耳/齐下巴/过肩",
    "texture": "服帖 | 蓬松 | 卷曲 | 细软",
    "fringe": "齐刘海 | 斜刘海（注明斜向本人哪一侧）| 无刘海 | 碎刘海",
    "accessories": "发箍/发夹/帽子/无（有就描述颜色样式）"
  },
  "ears": { "visible": true, "note": "大小、形状；普通就写'正常'" },
  "eyes": {
    "eyelid": "单眼皮 | 双眼皮 | 内双",
    "size": "偏大 | 适中 | 偏小（把握度，勿夸张）",
    "shape_gaze": "杏眼/细长/圆；直视/看向一侧/微眯",
    "color": "乌黑 | 深棕 | 蓝 | 绿…"
  },
  "expression": {
    "type": "微笑露齿 | 抿嘴笑 | 安静不笑 | 嘟嘴 | 酷酷的",
    "personality": "从表情推断气质：爱笑开朗 / 安静乖巧 / 古灵精怪 / 高冷"
  },
  "face_skin": {
    "face_shape": "脸型（圆/瓜子/苹果肌）",
    "skin_tone": "按照片实际观察描述：瓷白冷调 | 白皙暖调 | 自然浅麦 | 小麦色 | 蜜糖色 | 棕色 | 深棕色（禁止按族裔套默认值）",
    "skin_detail": "腮红/雀斑/晒痕等有辨识度的皮肤特征（有就写，也是 distinctive 候选）"
  },
  "distinctive": ["按辨识度排序的2-3个特征，生成时加权放大"]
}
```

## 第二步：生成 Prompt 拼装模板

```
【固定头】一张可爱幼童的大头贴贴纸，完整的头部（包含全部头发轮廓）居中放置在纯白色
背景上，头部只占画面中央约50%，四周大量留白，无脖子无肩膀无身体，像一张剪出来的头部
贴纸。{basic.ethnicity}{basic.gender}，{basic.age}。

【发型段】发型（最重点）：{hair.color}{hair.length}的头发，{hair.texture}；
{hair.fringe}。{if hair.accessories: 戴着{accessories}}。
{if ears.visible: 耳朵露出，{ears.note}}

【眼睛段】眼睛（重点）：{eyes.eyelid}，{eyes.size}、{eyes.color}明亮，
{eyes.shape_gaze}。

【表情段】表情（重点）：{expression.type}，{expression.personality}的感觉。
{face_skin}，皮肤细腻有真实婴儿肌理。

【辨识度段】{for f in distinctive: 特别注意（重点强调）：{f}。}

【固定尾】摄影级写实质感，柔和影棚光，发丝有细碎绒毛细节，头部边缘干净利落，纯白背景。
```

## 拼装规则

1. **放大原则**：`distinctive` 里的特征在文字上主动放大（耳朵大→"一对明显的可爱大耳朵"），普通特征平铺直叙。"像"来自放大辨识度特征，不来自平均。
2. **表情映射性格**：照片在笑→头像要笑；照片酷→头像做酷。不做统一美化。
3. **方向注意**：刘海/发缝的左右方向按"本人视角"写，并附"（即画面左/右侧）"双重锚定，文生图模型容易镜像搞反，需人工抽查。
4. **度的把握**：眼睛"偏大"≠夸张漫画大眼，所有 size 描述都带"保持自然真实比例"兜底。
5. **肤色忠实原则（海外红线）**：肤色只从照片读取，禁止默认"白皙"、禁止任何方向的提亮/美白。
   中文审美的"白=美化"在欧美市场是 whitewashing 争议雷区，深肤色用户被调白属于冒犯。
   雀斑、腮红等皮肤特征是辨识度资产，保留并可进 distinctive 放大。

## 已知局限

纯文字管线风格稳定，但五官细节是模型想象的（"符合描述的小孩"≠"本人"）。
上线版本需在此模板基础上叠加图生图（照片作为 image 输入），文字模板负责风格与特征加权。
